# Rock Paper Scissors - Cyber Arena

## Description

Rock Paper Scissors - Cyber Arena is a Python console-based game where the player competes against a computer opponent named CyberBot-3000. The game follows a Best-of-3 Championship format, where the first player to win two rounds becomes the champion.
The player enters a unique Gaming ID and chooses between Rock, Paper, or Scissors in each round. The computer generates its choice randomly, and the winner is determined using the standard game rules.

## Features

* User-friendly console interface
* Custom Gaming ID for the player
* Random computer opponent moves
* Best-of-3 match format
* Score tracking system
* Input validation for user choices
* Match winner announcement
* Option to play multiple matches

## Game Rules

* **Rock** beats **Scissors**
* **Scissors** beats **Paper**
* **Paper** beats **Rock**
* If both players choose the same option, the round is declared a tie.

## Technologies Used

**Language:** Python 3
**Libraries:** Random Module
**Tools & Platforms:** VS Code, Git, GitHub

## How to Run

1. Install Python 3 on your system.
2. Download or clone the project repository using Git/GitHub.
3. Open the project folder in VS Code or any Python IDE.
4. Run the Python file using:
python main.py

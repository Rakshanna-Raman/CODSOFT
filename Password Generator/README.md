# Smart Memorable Password Generator

## Overview

The Smart Memorable Password Generator is a beginner-friendly Python project that creates personalized passwords using user-provided words. Instead of generating completely random passwords, this program combines three meaningful words entered by the user and optionally adds a random number and a special character.

The user can also specify the desired password length, and the program adjusts the password accordingly while preserving the selected complexity options.

## Features

* Accepts three user-defined words.
* Allows users to include a random number in the password.
* Allows users to include a special character in the password.
* Generates passwords based on the desired length.
* Creates memorable and personalized passwords.
* Beginner-friendly and easy-to-understand Python code.

## Project Logic

1. The user enters three meaningful words.
2. The program combines the words into a single string.
3. If the user selects "yes" for numbers, a random digit is added.
4. If the user selects "yes" for symbols, a special character is added.
5. The program adjusts the password length according to the user's requirement.
6. The final password is displayed on the screen.

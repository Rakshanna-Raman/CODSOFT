# Nevermore Mission Log – Student Task Management Application

## Overview

Nevermore Mission Log is a Python GUI-based task management application designed to help users organize, track, and manage their daily tasks efficiently. Instead of a traditional to-do list, the application presents tasks as missions, creating a more engaging and interactive productivity experience.

Users can add, update, complete, and remove missions while maintaining a personalized mission log. The application features a clean graphical interface built using Tkinter and is designed to be beginner-friendly, intuitive, and easy to use.

## Features

* Personalized user greeting system
* Add new missions to the mission log
* Update existing missions
* Mark missions as completed
* Delete missions when no longer required
* Interactive Graphical User Interface (GUI)
* Real-time mission management
* Organized task tracking system
* Beginner-friendly design and implementation
* Custom themed user interface

## Technologies Used

**Language:** Python

## How to Run

1. Install Python 3 on your system.
2. Download or clone the project repository using Git/GitHub.
3. Open the project folder in VS Code or any Python IDE.
4. Run the Python file using:

python main.py

5. Enter your name.
6. Add, update, complete, or remove missions as required.

## Project Logic

1. The user enters their name.
2. The application displays a personalized welcome message.
3. The user enters a mission in the input field.
4. Clicking Add Mission stores the mission in the mission log.
5. Clicking Update Mission modifies the selected mission.
6. Clicking Complete Mission marks the selected mission as completed.
7. Clicking Banish Log removes the selected mission from the mission log.
